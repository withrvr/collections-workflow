# Screenshots

Add screenshots here under these exact filenames and they render inline
in `../README.md` automatically — nothing else needs to change.

| Filename | What to capture |
|---|---|
| `upload.png` | `/collections/upload` — the drag-and-drop dropzone |
| `run-detail-blocked.png` | `/collections/run-detail?runId=` for a `BLOCKED` run (dataset A) — the full colored stage timeline |
| `exception-expanded.png` | The exceptions panel with one card expanded, showing cause/impact/suggested fix/owner and the "Explained by" source badge |
| `summary.png` | `/collections/summary?runId=` — the block/pass banner, AI narrative, and region breakdown |

PNG or JPG, no fixed size requirement — GitHub scales them to the
container width. This folder is otherwise empty on purpose; it's not
built or referenced by any code path, only by the README.
